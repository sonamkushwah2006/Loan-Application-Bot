# Loan-Application-Bot
# 💰 Loan Application Bot

A simple and user-friendly **Loan Application Chatbot** built using **Node.js, Express, HTML, CSS, and JavaScript**.  
This web application helps users check **loan eligibility** by answering a few easy questions in a chat-style interface.

---

## 🚀 Features

- 🤖 Interactive chatbot-style interface
- 🏦 Supports multiple loan types:
  - Personal Loan
  - Education Loan
  - Home Loan
- 💬 Step-by-step guided conversation
- 📊 Instant loan eligibility check
- 🎨 Clean and responsive user interface
- ⚡ Fast backend powered by Express.js
- 🌐 Easy to deploy and run

---

## 🛠 Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
